# 牛牛 1.5.8 · 使用指南

[下载 Windows 版](https://github.com/Tagraysl/NiuNiu-Downloads/releases/latest) · [官网交互演示](https://tagraysl.github.io/NiuNiu-Downloads/) · [English](README.en.md)

牛牛把硬件状态和程序占用放在同一个工具里：完整窗口看细节，紧凑面板节省空间，任务栏随时查看关键指标。

## 电脑参数

| 模块 | 可查看的内容 |
|---|---|
| CPU | 占用率、逻辑处理器数量、设备提供的温度、频率与功耗 |
| GPU | 每块显卡的占用、显存、设备提供的温度、频率与功耗 |
| 内存 | 占用、已用/总容量、可用容量与提交上限；采集源提供时也可选内存温度 |
| 物理硬盘 | 活动率、读写速度、关联卷及设备提供的温度 |
| 磁盘/分区 | 空间占用、已用/总容量、可用空间、文件系统 |
| 主板 | 采集源提供的主板信息与传感器 |
| 网卡 | 链路占用与速率、下载/上传速度、累计收发量 |
| 网络节点 | 公网 IP、地区、ASN、运营商、连接概况及延迟 |

指标按模块类型提供，分区和网络不会套用硬件温度。额外传感器按设备实际读数列出；没有读到的数据不会当作零。

## 完整模式：安排自己的仪表板

- **卡片并排**：自动按窗口宽度排布。CPU、GPU 等类型标签帮助快速定位。
- **DIY 自定义行**：创建分组和子行、设置标签、调整顺序、分配或隐藏模块。
- **模块宽度**：选择 1–4 格或自动宽度。实际空间不足时自动换行。
- **模块参数**：点击模块 **⋯**，默认推荐三个参数，可勾选、取消、上下排序或恢复推荐。已有明确选择保留。
- **自适应排布**：按实际宽度和字体安排参数列数，参数较少时充分利用宽度；增加的参数始终在曲线上方。同一实际行的图表对齐，不同行独立计算高度。
- **长内容**：型号与参数内容放不下时水平滚动；悬停暂停，空间足够时完整显示。
- **模块曲线**：独立控制是否显示及显示哪些曲线；关闭显示不会清空选择。

曲线带指标名、纵轴单位和时间轴，不同单位分开绘制。每模块保留最近 60 个采样点，缺失读数处断开。

## 紧凑与任务栏模式

**紧凑模式**可调整大小、拖动、选择置顶，独立切换电脑参数与占用。可选自适应、自动滚动及轮播；内容全部放得下时保持静止。悬停或打开菜单时暂停自动滚动/轮播。

**任务栏模式**把指标放在 Windows 任务栏，文字颜色跟随系统。按住牛牛区域左右拖动，以 8 个逻辑像素为一格保存位置；滚轮切换指标组，双击展开完整窗口，右键打开设置与退出菜单。点击菜单外部或按 Esc 可取消菜单。

任务栏分组可自动轮播或手动切换；宽度、字号和位置可设置。三种模式分别保存显示选择，模块采样频率与宽度共用。完整与紧凑模式的拖动区域避开按钮等交互控件。

## 占用：查找正在消耗资源的程序

通过图标和名称辨认进程，输入名称或 PID 搜索；点击表头切换排序方向。支持 CPU、GPU、内存、读写、网络流量及估算能耗影响；名称支持 A–Z/Z–A。

- **应用视图**按可执行文件和子进程归组，括号显示进程数量；打开尝试恢复应用窗口，关闭请求正常退出，便于处理保存提示。
- **进程视图**逐个显示 PID；打开仅针对该进程的窗口，关闭结束该进程，不结束整棵进程树。可能丢失未保存内容，关键系统进程和牛牛自身有保护。
- 无法可靠归属的后台进程请在进程视图查看。应用 GPU 显示组内最高值。
- **能耗影响**分为很低、低、中等、高、很高，是基于资源使用的估算等级，不是实测瓦数。

## 配色、温度提醒与采样

提供浅色、深色及多套主题，可通过色盘生成配色，也可独立调整背景、卡片、文字和强调色。完整与紧凑模式共享配色；各模式独立设置字体、字号、加粗和显示内容。设置窗口支持“应用设置”预览，保存后保留；取消或关闭会撤回预览。

硬件占用率每 10% 一档，由绿经过蓝到红。模块温度阈值可自定义，三种模式共用；CPU 默认 85°C、GPU 核心 80°C、硬盘 60°C。达到阈值变红，降至阈值以下 2°C 恢复。

通用设置可开启 Windows 温度通知，默认关闭，提供测试通知。每次超温提醒一次，同一硬件至少间隔 5 分钟；Windows 勿扰和通知设置仍适用。

模块采样间隔可选 1/2/3/5/10/15/30/60 秒，控制实际读取频率。程序占用采样和公网资料刷新分别设置。

## 网络查询

本地网卡速度与累计流量独立采集；公网 IP、地区、ASN、运营商通过 Ping0 查询。默认启动时查询，之后每 10 分钟刷新，也可改频率、关闭自动查询或手动刷新。切换轮播不会额外查询。

高级资料需要用户自己的 Ping0 API 密钥，密钥用 Windows 当前用户加密保存。公网结果代表当前系统出口，不保证等同于浏览器专用代理或 VPN 客户端的节点名称。延迟使用可自定义目标的 ICMP 检测。

## 安装、自启与更新

支持 Windows 10/11 x64，安装包内置 .NET 运行环境。可选择安装目录和数据目录；卸载默认保留个人数据，也可选择删除牛牛的设置、密钥和日志；PawnIO 独立保留。监控程序请求管理员权限，部分 CPU/硬盘传感器需要 [PawnIO 驱动](https://pawnio.eu/)；安装器不会自动安装该驱动。当前安装包未取得发布者签名。本次仅提供 Windows 版本。

在 **显示设置 → 通用设置** 中选择开机自启，保存后生效；下次登录沿用上次显示模式。语言同样在通用设置中切换。

软件内可检查 GitHub 正式 Windows 版本，下载并校验安装包，确认后运行安装器。自动检查可关闭，开启时每 6 小时最多检查一次。手动升级沿用原安装及数据目录即可保留配置。尚无内置更新的旧版需手动安装一次。

## 指标口径与数据

- 容量按 1000 进位显示；CPU 占用按整机逻辑处理器数归一化。
- 进程 GPU 取最忙引擎；内存为工作集，口径可能不同于其他工具。
- 网卡占用相对标称链路速率，不是宽带套餐占用率。
- 进程读写包含文件、网络和设备 I/O；网络流量通过 ETW 统计，代理流量可能记在代理进程上，不宜简单相加。只统计字节与进程身份，不记录通信内容。
- 设置与监控在本机处理。启用公网查询会访问 Ping0，延迟检测访问指定目标，更新检查访问 GitHub；相应自动请求可在设置中关闭。
