把注意力留给正在做的事。
01

突然变慢？先看占用。

打开占用页，按 CPU、GPU 或内存排序，看看资源花在哪里。用图标辨认应用，也能按名称或 PID 精确查找。

02

长任务，留意变化。

渲染、编译或下载时，把负载、温度与读写曲线放在一起看。设置温度阈值，超温变红，也可开启 Windows 通知。

03

完整窗口展开细节，紧凑面板放在桌面一角，任务栏保留关键指标。各模式分别记住显示选择，按当前工作切换。

能看什么

从整机，到每个关键指标。

硬件状态与程序占用，在同一个地方查看。

CPU / GPU

看负载，也看运行状态

占用率、显存，以及设备支持的温度、频率与功耗。多块显卡分别查看。

RAM

内存还剩多少，一眼看清

已用与总容量、可用内存和提交上限，结合趋势观察变化。

SSD / HDD

硬盘在忙，还是空间快满了？

物理硬盘看活动率、读写速度和温度；分区看剩余空间与文件系统。

NETWORK

网速与连接信息，一起看

上传、下载、累计流量，以及公网 IP、地区、运营商和延迟查询。

PROCESSES

从整机状态，找到具体进程

按资源占用排序，按名称搜索；显示应用图标，支持打开与结束选中进程。

SENSORS

按设备挑选你关心的指标

查看采集源提供的主板与额外传感器，在模块设置中自由选择参数和曲线。

温度及额外传感器项目随硬件和驱动支持而定。

按你的习惯来

不必接受一张固定的仪表板。

从显示内容到摆放方式，都有自己的选择。

01

信息多少，你来决定。

勾选参数、调整顺序，独立选择曲线。完整模式会随实际宽度安排多列，参数始终放在图表上方。

02

把桌面排成顺手的样子。

卡片并排或 DIY 自定义行，模块可加宽、分组、隐藏。切换预设配色，或自己调整背景、文字与强调色。

03

常看的指标，留在手边。

任务栏按格左右拖动，滚轮切换指标组；采样间隔按模块设置。按需开启开机自启、温度通知和自动更新检查。

第一次使用，从这三步开始
  1. 打开“电脑参数”看硬件，或进入“占用”查找程序。
  2. 点击模块右上角的 ⋯，选择参数、曲线和采样间隔。
  3. 选一个显示模式，调整布局与配色；设置会保存在本机。

温度与安装有什么要求？

Windows 10/11 x64。监控程序需要管理员权限；可读取的温度取决于硬件与驱动，部分传感器需安装 PawnIO。当前安装包未取得发布者签名。

免费吗？数据保存在哪里？

当前版本可免费用于个人或企业内部。监控与设置保存在本机；公网信息查询会访问 Ping0，更新检查会访问 GitHub，均可关闭自动检查或查询。

在哪里查看完整功能和更新记录？

GitHub 提供完整功能说明、版本记录和反馈入口。升级沿用原安装及数据目录可保留配置；旧版首次升级需手动安装。
