# 牛牛 macOS 预览版 0.1.0

这是从 Windows 交叉编译得到的 **Mac 预览版**，尚未在 Mac 实机启动、验证或完成签名认证，不能视为与 Windows 功能一致的正式版本。

- Apple 芯片选择 `osx-arm64`，Intel 芯片选择 `osx-x64`，当前包面向 macOS 13 及以上。
- 解压后可把 `NiuNiu.app` 整体移动到“应用程序”、用户自己的 Applications 或其他文件夹。
- 首次启动可选择数据文件夹；默认 `~/Library/Application Support/NiuNiu/Data`。也可在设置中另选。数据不写进 `.app` 内，避免更新和签名损坏。移除程序后仍保留数据。
- 界面、共享配置及部分采集代码已完成，但没有 Mac 实机验证。温度、风扇、真实功耗、各程序 GPU/网络速率、磁盘读写率、独立显存尚未实现；高级 Ping0、色盘、拖放及菜单栏直接滚动文字等仍待移植。不会把没有读到的值伪装成 0。
- macOS 可能阻止未签名的预览版运行。所附脚本不关闭 Gatekeeper、不移除隔离属性。正式分发需要 Developer ID 签名、Apple 公证以及真实硬件测试。

详细的已实现内容、缺口、测试清单及未来签名流程见同目录 `README.en.md` 和 `sign-and-package.sh`。
