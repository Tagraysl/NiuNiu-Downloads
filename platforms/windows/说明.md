# 牛牛 Windows 1.5.2

- 占用率数字：完整、紧凑和任务栏三种模式统一每 10% 一档，从绿经蓝到红；明暗随主题调整，无数据保持中性色。
- 温度预警值：在硬件模块的“⋯”设置中，温度右侧可填写 20–120°C 整数或恢复默认。CPU 默认 85°C、GPU 核心 80°C、硬盘 60°C，每个硬件独立设置，三种模式共用。达到阈值变红，降至阈值以下 2°C 恢复。
- 可选 Windows 通知：显示设置 → 通用设置 → 温度超标时发送 Windows 通知，默认关闭。勾选后可发送测试通知，保存后生效。按后台主要温度判断，不受当前页面和字段可见性影响；每次超温提醒一次，同一硬件至少间隔 5 分钟，多硬件合并通知。Windows 勿扰和通知设置会影响实际显示。

双击 `NiuNiu-1.5.2-Windows-x64-Setup.exe`，选择安装语言、程序目录和数据目录。安装包已包含运行环境，可离线安装，不必单独安装 .NET。

- 开机自启：**显示设置 → 通用设置 → 开机自启 → 保存设置**。默认关闭，在当前用户登录 Windows 后启动；取消勾选并保存即可关闭。沿用上次显示模式，不保存 Windows 密码。移动程序文件夹后，请关闭再开启一次以更新启动路径；卸载前可先关闭自启。
- 字母排序：**占用 → 排序选择“名称”**，默认 A–Z；点击箭头或完整模式中的“程序”表头切换 Z–A。英文名称忽略大小写，同名按 PID 排列，搜索仍可使用。
- 默认完整窗口的 CPU、GPU 等表头完整显示；在小屏或手动缩窄窗口时，可以横向滚动查看全部列。

- 切换语言：**显示设置 → 通用 → 语言 / Language → 保存设置**。完整、紧凑、任务栏模式及托盘菜单同步切换。程序名、硬件型号、用户自写标题、路径、Ping0 返回的地名和运营商名称保留原文。
- 默认数据目录为所选安装目录下的 `Data`，也可选择其他位置。设置页显示当前数据位置。重新运行安装程序可以改选数据目录；下一次启动复制已有配置和加密密钥，保留原件，不覆盖目的目录已有设置。
- 从旧便携版升级时，如果新数据目录没有设置，会复制 `%LOCALAPPDATA%\ShilinMonitor` 的原配置及加密密钥。原有三种模式的内容、布局、配色和采样频率保持兼容。
- 卸载保留个人数据。更新前请从关闭提示中选择“完全退出”，再运行安装程序。旧版窗口尚未退出时，再次启动可能只会唤回旧版。
- 任务栏模式的牛牛区域可右键返回完整窗口，也可双击恢复。

安装程序本身使用普通用户权限。为保持硬件传感器和各程序网络流量统计，监控程序仍会请求管理员权限。传感器读数依赖硬件和驱动，不支持的项目显示未读到。

**新电脑上的温度读取：**部分 CPU 和硬盘传感器需要另外安装 PawnIO 驱动。安装结束页提供默认不勾选的 [PawnIO 官方下载页](https://pawnio.eu/) 入口，请选择已签名的 Official 版本。牛牛不会自动安装驱动，安装包中也不包含该驱动；下载需要联网，安装驱动需要管理员权限。没有驱动时仍能运行基础监控，不可读取的温度不会编造为正常读数；驱动也不能让不支持的硬件凭空提供传感器。

当前没有正式代码签名证书，安装包仍可能被 Windows 提示未知发布者或信誉不足。本程序不会关闭系统防护、添加杀毒排除项或伪造可信身份；这些提示也不能仅靠改变安装界面消除。正式公开分发还需签名及建立信誉。
